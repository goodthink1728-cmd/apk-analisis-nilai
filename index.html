📖 Petunjuk Singkat Penggunaan Aplikasi

Ikuti 4 langkah mudah berikut untuk menyelesaikan analisis ulangan Anda dalam hitungan detik:

1

Unduh Template Excel

Klik tombol Template Excel di bagian atas untuk mendapatkan format tabel baku nama dan nilai.

2

Import File Nilai

Klik tombol Import Excel untuk mengunggah file nilai Anda. Sistem membaca nama & nilai secara instan.

3

Periksa Grafik & Butir

Buka tab Analisis Butir Soal dan Ketuntasan untuk melihat grafik persentase serta kualitas soal.

4

Cetak Laporan Resmi

Klik Cetak Dokumen untuk mencetak bundel laporan A4 lengkap dengan Kop & Tanda Tangan pengesahan.
